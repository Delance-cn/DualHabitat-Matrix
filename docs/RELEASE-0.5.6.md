# DualHabitat Matrix 0.5.6

0.5.6 是 0.5.5 双实例版本的缺陷修复版，重点修桥接启动、厂商切换和本地模型识别。

## 修了什么

- **裸模型名不再把桥接带崩**：模型池里只有 `qwen3.5-4b-...` 这种没有 `provider/` 前缀的条目时，桥接会跳过它并等模型目录就绪后再按真实模型反查 provider，不再 `exit 1`。
- **切换厂商立即刷新连接**：选 DeepSeek、智谱、LM Studio 等厂商时，协议、接口地址和模型会一起更新，不会再把上一家的地址留在表单里。
- **本地模型识别**：LM Studio / Ollama / vLLM / llama.cpp / Jan 的探测结果直接进入模型候选；embedding 模型不会出现在聊天首选里。llama.cpp 增加 8080 端口探测。
- **自动修复 0.5.5 的坏配置**：启动桥接 / 微信前会做一次幂等修复，只补空的本地 provider 模型、只给能匹配的裸模型池条目加前缀，再重新生成 `opencode.json`。用户已经写好的 provider/model 和密钥不会被改。
- **模型池保存校验**：裸模型名、`/model`、`provider/` 这类写法在界面入口和保存接口都会被拒绝，并给出正确写法示例；保存后返回被丢弃的条目和警告。
- **“模型与 API”面板重做**：顶部新增当前平台 / 厂商 / 模型 / 地址 / key 状态 / 模型池 / 服务状态摘要；生成参数、批量导入、模型价格默认折叠；模型池增加候选列表、非法条目标记和“把当前模型放到池首”。
- **自动保存不再每个字符重启服务**：改为失焦 / 选完时保存，并恢复“保存并应用”按钮。

## 验证

- `desktop/scripts` 18 项测试全部通过。
- 双实例 30/30、provider 73/73、model-chain 42/42、model-pool 50/50、failover 47/47。
- 隔离数据根实测：0.5.5 的裸模型池和空 `chat.model` 能被自动修复，桥接稳定启动。
- 真实 LM Studio 模型完成一次对话回复（`1+1` → `2`）。
- 真实图片生成成功（Cloudflare flux，1024×1024 JPEG）。
- 浏览器检查“模型与 API”页：厂商切换、地址/模型刷新、本地模型候选、模型池非法条目标记和保存丢弃均正常，无 console error。

## 已知限制

- 语音发送依赖 `audio/` 语音库或可用 TTS；当前测试环境的 Edge TTS 和 SAPI 都失败，语音库为空，因此未能在真实 QQ 环境验证语音发送。
- QQ 空间动态依赖 NapCat 的 QQ 空间扩展；当前 NapCat 对 `get_qzone_msg_list` 返回“不支持的Api”，需要升级或更换支持该扩展的 NapCat。
- 图片生成已验证可用；图片发送仍取决于 NapCat 和 QQ 账号权限。
