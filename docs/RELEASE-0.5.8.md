# DualHabitat Matrix 0.5.8

0.5.8 三件事：软件本体自更新接上镜像前缀（和 NapCat 同一套）、安装包下载加进度条、「API 与模型」页新增用量统计面板。

## 加了什么

- **软件本体自更新支持镜像前缀**：之前镜像前缀只做在了 NapCat / ffmpeg 的下载上，本体的安装包下载是裸直连。现在「高级 → 更新 → 软件下载镜像前缀」（`app.updateMirror`）填上（比如 `https://ghproxy.cn/`），安装包下载地址会拼成 `镜像/原始URL`；版本查询仍然直连 GitHub API。下载失败且没填镜像时，错误提示会带上镜像填写建议。
- **安装包下载进度条**：点「下载并安装」后，横幅里出现实时进度条（每秒刷新，显示百分比和已下载 / 总大小）。服务端新增 `/api/app/update/progress`；下载改走和 NapCat 同一个带看门狗的下载器 —— 90 秒收不到任何数据会自动断开并提示，不再傻等 10 分钟超时。
- **用量统计面板**：「API 与模型」页顶部新增。数据从 OpenCode 本地会话库（`opencode.db`，只读）来，每条助手消息记了成本、五类 token 和请求各阶段的时间戳，QQ 和微信两个实例一起统计：
  - 四张概览卡：总成本、请求次数（成功 / 失败分列）、消耗 Tokens（入 / 出分列）、缓存命中率（命中 token 数）。
  - 每日用量热力图：最近 26 周 GitHub 风格方格，颜色越深当天用得越多，悬停看当天请求 / token / 成本。
  - 请求日志：最新 100 条，含时间、应用、模型、成本、输入 / 输出 / 缓存 token、出字速度（tok/s）、首字延迟、成功 / 失败（失败悬停看原因）。
  - 打开页面自动加载，也可手动刷新。旧版模型池那行「调用 N 次」文本保留不动，这个面板是完整版。

## 验证

- `desktop/scripts` 18 个测试文件 42 用例全部通过。
- 真实会话库实测：738 条请求（654 成功 / 84 失败）、消耗 412.5 万 tokens、缓存命中率 72% 正确汇总；错误消息（免费额度用尽 403）进请求日志并标「失败」，悬停可见原因。
- 浏览器实测：面板四卡 / 热力图 / 日志表格渲染正常；`app.updateMirror` 保存回路（POST /api/settings → 落盘 → GET 回读）通过；进度接口空闲时返回 `{"active":false}`。

这两个版本的自动提示有缺陷（0.5.7 已修），请到 GitHub Releases 手动下载，或在旧软件里「高级 → 更新 → 立刻检查一次」后从总览横幅升级。直连下不动的，先用浏览器把 0.5.8 装上，之后就能在软件里填镜像前缀了。
