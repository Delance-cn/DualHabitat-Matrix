# QQ 官方机器人配置指南

0.6.0 起可用。这是独立于 NapCat 的**官方通道**：机器人在腾讯开放平台注册、带官方机器人标识、走官方接口，没有个人号协议（NapCat）的封号风险。私聊、群聊都能用。

## 它和 NapCat 那条线的关系

| | NapCat（原有） | 官方机器人（新增） |
|---|---|---|
| 本质 | 个人号协议，功能全（群管理、表情、图片…） | 开放平台官方接口，带机器人标识、不封号 |
| 账号 | 你自己的 QQ 号 | q.qq.com 注册的机器人（如 L.A.N） |
| 人设 / 模型池 | 共用同一份（`roles/`、`models.json`、4599 实例） | 同左 |
| 会话 / 记忆 | 独立 | 独立（两边互不串门） |
| 能不能同时开 | 能，互不影响 | 同左 |

建议用法：日常群里用 NapCat（功能多）；怕风的场景（陌生群、私聊对外服务）挂官方机器人。

## 配置步骤

1. **注册机器人**：到 <https://q.qq.com>（QQ 开放平台）→ 「创建机器人」，按提示完成资料。个人开发者即可创建，私聊立即可用；**群聊**要平台审核通过群聊权限（未上架机器人会标注「暂不支持进入群聊」——权限开通后本功能零改动直接生效）。
2. **拿凭证**：机器人管理页的「开发设置」里有 **AppID**（一串数字）和 **AppSecret**。AppSecret 只在首次展示，忘了就点重置拿一份新的。
3. **填进软件**：桌面端 → QQ 通道 → 「当前状态」页 → **「QQ 官方机器人」** 面板：
   - AppID、AppSecret 填入（Secret 只存本地 `config.json`，界面不回显）
   - 勾「启用官方机器人（群聊 + 私聊）」
   - 点 **「保存并启动」**
4. **看到「已连接（机器人『你的机器人名』）」就成了**。之后随软件自启，掉线自动重连，意外退出看护会拉起。

## 测试

- **私聊**：机器人管理页点「扫码聊天」（或让测试人员搜机器人名字添加），发一句话。第一条会慢十几秒（要现拉模型实例），之后正常。
- **群聊**：把机器人拉进已开通权限的群，**@机器人** 说话（官方接口只收 @ 消息）。

## 官方接口的限制（与 NapCat 的差异）

- **被动回复窗口**：收到消息后 **5 分钟内**回复算被动（不占主动额度），每条消息最多被动回 4~5 次；软件自动管理（msg_seq 递增、超限降级主动发送）。
- **主动消息频控**：每分钟条数有限（认证后 60/分钟、未认证 30/分钟，每群每天 1000 条）。机器人主动找人聊天的场景基本用不满。
- **群聊只收 @ 消息**：不像 NapCat 能看到群里所有话。
- **图片/Markdown/键盘**：本期只做了文本收发（长文自动分段），富媒体后续版本加。

## 出问题了看哪

「高级 → 日志」页，筛选 **官方QQ**：

| 日志 | 意思 |
|---|---|
| `access_token 就绪` / `网关就绪（会话 …，机器人「名字」）` | 一切正常 |
| `换 access_token 失败` | AppID/AppSecret 不对，回面板重填（Secret 重置过就要填新的） |
| `QQBot 鉴权被拒（INVALID_SESSION）` | 凭证失效或接口规则变化，软件会自动换备用格式重试一次 |
| `被动回复被拒（40034128…），这段改主动发` | 超过 5 分钟窗口/次数，正常降级，不是故障 |
| `网关要求重连` / `断线恢复（resume）成功` | 网络抖动，自动处理 |

状态文件在 `state/qq-official-status.json`（连接状态、机器人名、收发计数），桌面面板读的就是它。
