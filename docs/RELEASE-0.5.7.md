# DualHabitat Matrix 0.5.7

0.5.7 修复「有新版本却没有任何提示」的问题。0.5.5 / 0.5.6 的自动更新检查存在两处缺陷叠加：查到的更新被静默吞掉，而且错过之后长期不再复查 —— 用户看到的正是「没弹更新提示、没有向下箭头、没有任何提醒」。

## 修了什么

- **自动检查到的更新不再被静默吞掉（核心 bug）**：旧版自动检查在记「发现 vX 版」时顺手把"已提醒"标记（`lastReminded`）写成同一个值，而界面按「发现版本 ≠ 已提醒版本」显示横幅 —— 等于一查到新版本就替用户点了「忽略这个版本」，横幅、角标永远不会出现。只有手动点「立刻检查一次」才碰巧能看到（手动检查不写这个标记）。现在"已提醒"标记只由「忽略这个版本」按钮写入，自动查到的更新会正常亮出横幅。
- **更新检查时机**：旧版只在启动后查一次，且 20 小时内不复查 —— 发行版发得晚，用户重启软件也等不到提示。现在启动后必查（仅 10 分钟内成功查过才跳过，防快速重启连环请求 GitHub），软件运行期间每 30 分钟复查一次，开着不动也能等到新版本。
- **全局更新入口**：更新横幅只在总览页，待在 QQ / 微信通道页里的人收不到任何提示。侧栏底部新增「↓ 有新版本」按钮（亮色高亮），任何页面都看得见，点击回到总览页升级；导航「总览」角标逻辑保留。
- **气泡提醒**：检测到新版本时弹一次气泡（每次开软件最多一次），之后靠指示按钮常亮，不再打扰。
- **NapCat 更新检查同款问题一并修复**：同样的"顺手忽略"缺陷和 20 小时不复查问题都在 NapCat 检查里存在，已同步修复；另外周期检查不再往日志里刷「NapCat 已是最新」。

## 验证

- `desktop/scripts` 18 个测试文件 42 用例全部通过。
- 隔离数据根冒烟实测：启动约 20 秒后自动检查生效，`found` / `reminded` 记账正确（不再写"已提醒"标记），提醒日志每个版本只发一条，日志去重正常。
- 浏览器实测整条提示链路：总览横幅出现、气泡弹出且只弹一次；进入 QQ / 微信通道页侧栏底部「↓ 有新版本」按钮可见，点击回到总览；点「忽略这个版本」后横幅与指示按钮一起消失，`lastReminded` 由忽略接口写入。
- 版本比较、检查失败重试路径（失败不写检查时间，网络恢复后下次启动即重查）行为保持不变。

## 给 0.5.5 / 0.5.6 用户的升级说明

这两个版本因为上述 bug 自动等不到本版的提示，两个办法任选：

1. 到 GitHub Releases 页手动下载 `DualHabitat-Matrix-Setup-0.5.7.exe` 安装；
2. 在旧软件里打开「高级 → 更新 → 立刻检查一次」—— 手动检查不受 bug 影响，检查后总览页会出现更新横幅，点「下载并安装」即可。
